# 极致模式部署指南

极致模式适用于受 Python 包限制的 QMT 环境。请在 Web 控制台绑定页选择“极致模式”，填写 QMT 目录并保存，系统自动部署自包含托管策略和身份配置。

保存后按提示重启或登录 QMT，使用“检测连接”确认上线。无需复制代码、创建策略或手动放置入口文件。

导入 QMT 的极致模式策略直接使用 `CFQUANT_LITE.py` 的源码（沪深独立市场使用对应的 `_SH` / `_SZ` 文件），不使用 `exec`，不再在源码前拼接文件锁或控制文件包装。部署副本只替换账号配置和必要的编码转义；通用模式同样直接使用对应入口源码。

极致、通用模式在 QMT 内不再读写配置 JSON、日志、状态标记或锁文件，也不扫描源码文件或清理磁盘日志。账号和通道配置由外部部署程序填入 `EMBEDDED_RUNTIME_CONFIG`，日志输出到 QMT 控制台，运行状态和模式停用通过现有命名管道传输。命名管道用于进程通信，不创建磁盘文件。Web 端仍可保存自己的部署记录和状态文件。托管策略首次启动时须由 Web 通过管道确认模式后才接受业务请求；手工复制的入口可编辑内嵌配置或使用 `CFQUANT_RUNTIME_CONFIG_JSON` 环境变量。

更新后重启 cfquant 服务，在对应 QMT 退出后重新保存绑定，待策略重新导入后启动 QMT；已经导入的旧策略不会因为仓库文件修改自动换成新代码。
